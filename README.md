# Ming Gao — Portfolio

Personal portfolio of Ming Gao, Computer Engineering student at UBC (Richmond, BC).

- **`index.html`** — the public portfolio (this is what GitHub Pages serves).
- **`studio.html`** — a single-file, no-build studio for editing the portfolio (drag-and-drop layout, live preview, theming, 3D models).
- **`assets/`** — project cover images.

Built as a single-file vanilla-JS site. No build step: open `index.html`, or run `node serve.js` for a local server.

Live site: enabled via GitHub Pages.
